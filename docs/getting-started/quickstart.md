# Quickstart

This short path helps new users find their way through the documentation.

1. Review the [installation prerequisites](installation.md).
2. Follow the setup instructions for your environment.
3. Browse the [guides](../guides/index.md) for common tasks.
4. Use the [reference](../reference/index.md) when you need detailed
   specifications.

If a step does not match your environment, consult your project administrator
for the applicable setup details.
