# Code of Conduct

## Our standards

We want participation in this project to be welcoming and respectful. Please:

- Be considerate and constructive when discussing ideas and reviewing work.
- Respect differing viewpoints and experiences.
- Focus feedback on the work, not the person.
- Accept responsibility for mistakes and help make things right.

Harassment, discrimination, personal attacks, and other disrespectful conduct
are not acceptable.

## Scope and enforcement

This code applies in project spaces, including issues, pull requests, and
discussions. Maintainers may remove content or restrict participation when
conduct violates these standards. To report a concern, contact a repository
maintainer privately through GitHub.
